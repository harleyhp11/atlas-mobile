# Template setup

This archive is an attributed copy of the Arfazrll portfolio.

Before publishing your own site, replace the name, biography, contact details, social links, resume, project content, photographs, certificates and brand assets with your own material.

The main portfolio content lives in `src/data/portfolio.ts` and the localized interface copy lives in `messages/`.

Optional live integrations use `NEXT_PUBLIC_GITHUB_USERNAME`, `GITHUB_TOKEN`, `WAKATIME_API_KEY`, `GROQ_API_KEY` and `GEMINI_API_KEY`.

See `ATTRIBUTION.md` for the upstream repository, pinned commit and licence.
